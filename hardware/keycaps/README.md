# Keycaps — Halcyon Ferris

The Halcyon Ferris uses **Kailh Choc v1** switches on **Choc spacing (18 × 17 mm)**,
so keycaps must have a Choc v1 stem and be Choc-sized (~17.5 × 16.5 mm).
MX-spaced (~18 mm wide) caps collide with their neighbours.

## KEA profile (`kea/`)

Source: <https://github.com/klouderone/KEA-choc-keycaps> by Kea Workshop.

Files are from the repo's `KEA Choc V1 Choc Spaced (18x17mm)` folder
(the ~16.5 mm wide variant, not the MX-spaced ~18 mm one).

| Qty | File | Key positions |
|-----|------|---------------|
| 28 | `KEA Choc V1 Choc Spaced Keycap 1u.stp` | all alphas except F/J |
| 2 | `KEA Choc V1 Choc Spaced Homing Keycap 1u.stp` | 13, 16 (F / J) |
| 4 | `KEA Choc V1 Choc Spaced Thumb Keycap 1u.stp` | 30–33 (thumbs) |

Print a couple of spares of each.

## Print settings (Bambu Lab A1, 0.4 mm nozzle, PLA)

Based on the author's settings (X1C, eSun PLA+). Black PLA hides layer lines best.

- Orientation: **standing upright** (layer lines parallel to the stem prongs so they
  don't shear off in the switch)
- Layer height: 0.08 mm
- Line width: 0.42 mm
- Wall loops: 3
- Infill: 100 %
- Speed: 20 mm/s for everything
- Support: painted manually, **only under the stem prongs**; style Snug;
  top/bottom Z distance 0.08 mm; 2 interface layers
- Brim: yes

Print 1–2 caps first and check the stem fit; adjust X/Y scale ±1 % if needed.
Prefer PLA over PETG (more dimensionally accurate, stiffer stems).
